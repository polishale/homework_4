# Аналізатор тексту та порівняння бібліотек (`re` vs `nltk`)
 Ця програма зчитує файл, підраховує загальну кількість слів, формує словник частотності та обробляє можливі помилки читання.

## Структура 

- `text_analyzer.py` — головний модуль (зчитування файлу, підрахунок слів, обробка винятків).
- `test_analyzer.py` — 4 автоматизовані тести на базе `unittest`.
- `sample_text.txt` — текст для аналізу (~300 слів про прикладну лінгвістику).
- `README.md` — опис проєкту та порівняльний аналіз інструментів.

## Порівняння бібліотек `re` та `nltk`

| Параметр порівняння | Модуль `re` (Стандартна бібліотека) | Бібліотека `nltk` |
| :--- | :--- | :--- |
| **1. Призначення** | Швидкий пошук та розбиття рядків за шаблонами | Повноцінна обробка природної мови (NLP) |
| **2. Основні можливості** | Виділення слів за допомогою regex, очищення від розділових знаків | Токенізація, лематизація, вилучення стоп-слів |
| **3. Підтримка мов (укр/англ)** | Універсальна (працює з будь-якими Unicode-символами) | Ідеально для англійської; для української потрібні додаткові моделі |
| **4. Простота використання** | Проста, достатньо базових знань регулярних виразів | Потребує вивчення API та завантаження словників |
| **5. Потреба у встановленні** | Ні (вбудований модуль Python) | Так (`pip install nltk`) |
| **6. Приклад використання** | `words = re.findall(r"[a-zA-Zа-яА-ЯіІїЇєЄґҐ']+", text)` | `words = word_tokenize(text)` |

## Як запустити проєкт

1. **Створення та активація віртуального оточення:**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   ```

2. **Запуск аналізу тексту:**
   ```bash
   python text_analyzer.py
   ```

3. **Запуск автоматичних тестів:**
   ```bash
   python -m unittest test_analyzer.py
   ```
